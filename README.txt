PÁGINA ROMÁNTICA PARA QR

1. Abre index.html en un navegador para probarla.
2. Antes de publicarla, abre index.html con un editor de texto y cambia:
   const PASSWORD = "Ericka2026";
3. Publica toda la carpeta (index.html + carpeta assets) en un servicio de hosting estático.
4. Cuando tengas la URL pública, esa URL será la que debe contener el QR.
5. El sitio incluye noindex/nofollow para pedir a buscadores que no lo indexen.

IMPORTANTE SOBRE LA CONTRASEÑA:
La pantalla de contraseña incluida es una barrera del lado del navegador, no seguridad de servidor. Si quieres privacidad fuerte (que los archivos no sean accesibles sin autenticación), conviene usar un hosting que permita protección real con contraseña. Podemos preparar esa versión cuando elijas dónde publicarla.
